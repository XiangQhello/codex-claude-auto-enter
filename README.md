# 解放单手（分享版）

“解放单手”是一个适用于 Codex、Claude Code 等终端 AI Agent 的多任务定时回车工具。每个任务绑定一个固定窗口，只有手工重新选择时才会改变目标。

## 功能

- 鼠标点击并锁定普通终端窗口；
- 多个终端同时运行独立任务；
- 支持按一次或循环发送；
- 支持手动停止、总次数和总时长；
- 每个任务可单独停止、按原配置重新运行、更换目标或删除；
- 运行中点击“重新运行”会安全停止当前轮次，再自动开始新一轮；
- 已创建的任务可修改发送方式、间隔、次数和持续时间，无需重新创建；
- Qt 原生高 DPI 界面和跨平台中文字体；
- Linux、macOS、Windows 一键启动。

Claude Code 不需要专用协议：先在普通终端中启动 `claude`，再点击“选择普通终端窗口”锁定该窗口即可。工具只按固定窗口标识定时发送 Enter，不读取或依赖 Claude Code 的输出格式。

## 一键启动

启动器会优先复用当前带有 PyQt5 的 Conda/Python 环境；找不到兼容环境时，才会创建一次本地 `.venv`。

### Linux

```bash
chmod +x 一键启动.sh
bash 一键启动.sh
```

终端会显示实际使用的 Python/Conda 环境、启动 PID、启动是否成功和退出码。关闭图形窗口即可退出，也可以在启动终端中按 `Ctrl+C`。

### macOS

在 Finder 中双击“一键启动.command”。首次发送前，需要在“系统设置 → 隐私与安全性 → 辅助功能”中授权。

### Windows

双击“一键启动.bat”。首次启动可以自动安装依赖并创建桌面快捷方式。

## 使用方法

1. 点击“选择普通终端窗口”。
2. 用鼠标点击目标终端。
3. 设置按一次或循环、回车间隔、次数或持续时间。
4. 点击“添加并启动任务”。
5. 继续选择其他终端即可并行运行。
6. 点击“修改设置”可调整发送方式、间隔、次数或持续时间；运行中保存会安全重启。
7. 点击“重新运行”可沿用同一终端和全部规则；运行中点击会安全重启。
8. 使用任务卡上的“停止”或右上角“全部停止”结束任务。

## 平台说明

| 平台 | 后台发送 | 说明 |
|---|---|---|
| Linux X11/Xorg | 支持 | 不抬起目标窗口，不改变活动窗口 |
| Linux Wayland | 不支持 | 请登录 X11/Xorg 会话 |
| Windows | 实验支持 | 终端需要接受 Win32 后台键盘消息 |
| macOS | 实验支持 | 需要辅助功能权限 |

## 目录结构

```text
解放单手/
├── 一键启动.sh / .command / .bat
├── src/                    程序源码
├── scripts/install/        自动安装脚本
├── scripts/build/          打包脚本
├── tests/                  自动测试
├── EDITION                 版本标识
├── requirements.txt        Python 依赖
└── VERSION                 版本号
```

## 打包

生成跨电脑安装包：

```bash
bash scripts/build/制作跨电脑安装包.sh
```

生成无需 Python 的独立版本：

```bash
bash scripts/build/打包独立版.sh
```

Windows 独立版使用 `scripts/build/打包独立版.ps1`。

## 安全提醒

定时回车不会判断 Codex 或 Claude Code 的终端内容。请只绑定专用任务终端，并限制运行次数或持续时间。不要把它用于自动批准删除、覆盖、发布或其他需要人工判断的危险操作。
