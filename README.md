# 解放单手（自用版）

“解放单手”是一个适用于 Codex、Claude Code 等终端 AI Agent 的多终端并行自动回车控制台。每个任务都绑定一把独立的目标锁：只有你手工选择终端时，任务的目标才会改变。任务启动后，你可以继续使用鼠标点击其他终端、浏览器或编辑器。

## 核心功能

- 手工点击终端，锁定固定窗口；
- Herdr 中可直接从 Pane 列表选择 Codex、Claude Code 或普通 Pane，通过 Herdr 官方 API 定向发送；
- 多个终端同时运行不同的自动回车任务；
- 第一次回车前等待一个完整时间间隔；
- 支持按一次或循环发送；
- 循环任务支持手动停止、总次数、总时长，或在 Herdr 中的 AI 任务完成后自动停止；
- 每个任务可单独停止、按原配置重新运行、更换终端或删除；
- 运行中点击“重新运行”会安全停止当前轮次，再自动开始新一轮；
- 已创建的任务可修改发送方式、间隔、次数和持续时间，无需重新创建；
- 支持一键全部停止；
- Qt 原生界面，高 DPI、系统中文字体和跨平台缩放；
- Linux、macOS、Windows 安装与启动脚本。

## 保护锁与后台发送

每张任务卡保存自己的原生窗口标识。任务运行时不会根据鼠标位置或当前活动窗口重新寻找目标，所以点击别的终端不会改变发送对象。

在已经验证的 Linux X11 模式下，发送时只短暂改变 X 键盘焦点，不抬起目标窗口、不改变活动窗口、不改变窗口前后顺序。目标终端可以被其他窗口遮挡，不需要保持在前台，但不要最小化或关闭。

如果两个任务恰好同时到点，发送引擎会用一个毫秒级互斥锁依次发送，防止焦点竞争；两个任务的计时和停止控制仍然互相独立。

## 一键启动

把整个“解放单手”目录复制到目标电脑。启动器会优先复用当前可用的 Conda/Python 环境；只有找不到带 PyQt5 的兼容环境时，才会创建一次本地 `.venv`。之后不会反复新建。

### Linux

```bash
chmod +x 一键启动.sh
./一键启动.sh
```

终端会显示实际使用的 Python/Conda 环境、启动 PID、启动是否成功和退出码。关闭图形窗口即可退出，也可以在启动终端中按 `Ctrl+C`。

如果当前 Conda 环境已经安装 PyQt5，直接在激活该环境的终端运行即可复用它：

```bash
conda activate 你的环境
./一键启动.sh
```

也可以临时指定解释器：

```bash
HANDSFREE_PYTHON=/路径/到/python ./一键启动.sh
```

只有缺少兼容环境时，首次启动才会创建独立虚拟环境、安装 Qt 依赖并检查 `xdotool`。安装流程还会创建应用菜单入口和 `handsfree-enter` 命令。

### macOS

在 Finder 中双击“一键启动.command”。首次启动会自动安装依赖；首次发送前，需要在“系统设置 → 隐私与安全性 → 辅助功能”中授权。

### Windows

双击“一键启动.bat”。首次启动会自动安装依赖并在桌面创建“解放单手”快捷方式。电脑需要已安装 Python 3；如果系统带有 `winget`，安装程序也可以自动安装 Python。

## 目录结构

```text
解放单手/
├── 一键启动.sh / .command / .bat   三个平台的用户入口
├── src/                             程序源码
├── scripts/install/                 自动安装脚本
├── scripts/build/                   安装包与独立版构建脚本
├── tests/                           调度器测试
├── requirements.txt                 Python 依赖
├── VERSION                          版本号
└── README.md                        使用说明
```

普通使用只需要根目录的“一键启动”文件，其余实现文件已经分类收纳。

## Herdr 中使用 Codex 或 Claude Code

Herdr 内的 Codex 和 Claude Code 都运行在 Herdr 管理的独立伪终端中，不应当选择外层 GNOME Terminal 窗口。启动工具后点击“选择 Herdr AI Agent / Pane”，从列表中选择具体 Pane。程序会优先显示规范化的 `Codex` 或 `Claude Code` 名称；回车通过 `herdr pane send-keys <pane> enter` 直接送到该 Pane，不要求 Herdr 或目标 Pane 位于前台。

循环任务还可以选择“AI 任务完成后自动停止（推荐）”。工具会读取 Herdr 的 Pane 状态：`working` 和 `blocked` 会继续发送，变为 `idle` 后停止。`blocked` 表示 Codex/Claude Code 正在等待确认或输入，仍可能需要回车；如果无法确认实时状态，任务会安全地异常停止，不再盲目发送。该选项只对列表中识别为 Codex 或 Claude Code 的 Pane 开放。

左侧的“AI 状态检查间隔（全局）”可以在 `0.5～10 秒`之间调整，默认 `1 秒`。它只控制 Pane 状态轮询频率，不改变回车发送间隔；修改后对当前运行中的 AI 自动停止任务生效。无论轮询间隔多长，每次真正发送回车前都会额外确认一次状态。

普通终端仍然使用“点击选择普通终端窗口”。程序会把误选到的内部控件自动提升为所属主窗口，减少嵌入式终端无法接收按键的问题。

## 制作跨电脑安装包

在 Linux/macOS 中运行：

```bash
./scripts/build/制作跨电脑安装包.sh
```

脚本会在上一级目录生成 `解放单手-自用版-版本号.zip`，并排除虚拟环境、缓存和构建产物。

## 版本管理

- `main`：只包含普通终端功能，用于公开分享；
- `personal/herdr`：你的自用版本，额外包含 Herdr Pane 定向发送；
- 两个版本使用独立 worktree，公共修复可以通过 Git 合并或挑选提交同步。

## 平台能力说明

| 平台 | 选择目标 | 后台发送 | 当前状态 |
|---|---|---|---|
| Linux X11/Xorg | 鼠标点击窗口 | 不抬起、不切活动窗口 | 已在本机真实验证 |
| Linux Wayland | 系统禁止任意窗口注入 | 不支持 | 请登录 X11/Xorg 会话 |
| Windows | 鼠标点击窗口 | Win32 后台窗口消息 | 已实现，终端兼容性取决于终端程序 |
| macOS | 鼠标点击窗口 | Quartz 按进程投递 | 已实现，需要辅助功能权限 |

Windows Terminal 等采用特殊输入架构的终端可能拒绝后台 Win32 键盘消息；macOS 同一终端应用的多个窗口可能由同一进程管理。跨平台界面、调度器和安装流程是一致的，但系统安全模型决定了后台注入能力的上限。

## 使用流程

1. Herdr 用户点击“选择 Herdr AI Agent / Pane”；普通终端用户点击“选择普通终端窗口”。
2. 设置按一次/循环、间隔、次数或持续时间。
3. 点击“添加并启动任务”。任务会出现在右侧并获得独立保护锁。
4. 左侧设置会保留，目标会清空；继续选择第二个终端即可并行添加。
5. 点击“修改设置”可调整发送方式、间隔、次数或持续时间；运行中保存会自动安全重启并应用新设置。
6. 点击“重新运行”即可沿用同一个终端和全部时间规则；运行中点击会先安全停止再自动重启。
7. 紧急情况下点击右上角“全部停止”。

## 生成无需 Python 的独立版本

独立版本必须在目标操作系统上分别构建，不能在 Linux 上直接生成 Windows/macOS 程序。

Linux/macOS：

```bash
./scripts/build/打包独立版.sh
```

Windows：右键使用 PowerShell 运行 `scripts/build/打包独立版.ps1`。

构建结果位于 `dist/`。

## 安全提醒

自动回车会确认目标终端当时显示的内容。建议每个目标窗口只运行 Codex 或 Claude Code，不要留下尚未执行的半条命令，也不要把自动回车用于自动批准需要人工判断的危险操作。
